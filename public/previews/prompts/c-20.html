How these tiles work

Every effect is plain CSS, wired to :hover and :focus-within so the keyboard gets the same six states as the pointer. The prints are inline SVG in flat riso inks, overprinted with mix-blend-mode: multiply, so no image files load.

With motion reduced, each state arrives at once. The zoom and the tilt, the two effects that travel, swap for a still highlight.
