Six hover effects, no JavaScript

A work grid where each tile answers the pointer differently. Every effect here is plain CSS — transforms, filters, clip-path and one :has() selector — and every one of them is wired to :focus-within as well as :hover, so the grid behaves the same for someone tabbing through it.

Tab moves through the six tiles and fires the same states hovering does.
