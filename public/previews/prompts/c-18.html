Five looping micro-animations for waits under ten seconds. Each one is plain CSS and inline SVG — no animation runtime, no JSON payload, nothing to load before the loader can appear. All five inherit currentColor, so they take the colour of whatever they sit inside.

Motion is reduced on this device. Every specimen below is shown at its designed rest frame — the state each one holds when animation is switched off. None of them are blank or half-drawn.

Why there is no runtime here These were specified for export to a vector animation format, but every one of them is reproducible in about ten lines of CSS. Shipping a player and a JSON file to draw three pulsing dots costs more than the wait it is covering.

The rule that matters Each specimen is authored at its rest frame and the animation is layered on inside @media (prefers-reduced-motion: no-preference). Switch motion off and you get a still loader, never an empty box.
