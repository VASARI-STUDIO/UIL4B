## Overview

The stylesheet is the design system. `src/styles/global.css` holds every live
token value, and `docs/reference/design-language-v2.md` records the shipped V2
language with its founder-approved deviations. **This file is a generated
mirror, written because Impeccable needs a machine-readable token layer. It is
never the place to change a value.**

Three surfaces, one system: Create (the tools), Discover (the libraries), Learn
(the articles). Continuity between them is a product property rather than a
nicety — the whole claim is that a designer does not have to leave to do the
next step.

## Colors

**Both themes are shipped surfaces**, three-state: Light / Dark / System. Every
new surface is checked in both, and `tests/user-sim/41-theme-control.spec.js`
holds it. The frontmatter carries the LIGHT values because the format takes one
set; the dark values sit beside them in `[data-theme="dark"]`.

The accent is #0F6FFF in light and #6FA8FF in dark, and it is the only
saturated colour in the interface. Everything else is a warm neutral ramp, so
anything accent-coloured is claiming to be the next action. Spend it accordingly.

Accent-family text has an AA floor that is asserted rather than assumed:
`tests/user-sim/39-accent-contrast.spec.js` fails any accent text under it.

## Typography

One family does every job. Manrope for interface, headline and display; JetBrains
Mono for values, labels and anything a user copies. There is no third face.

**The hero headline is sized by height as well as width** —
`clamp(46px, min(6.6vw, 9.5svh), 96px)` — because a laptop is wide and short, and
a width-only clamp let the headline take 46% of a 780px-tall screen. It now holds
a flat ~36%. This is the only headline on the site carrying a height term; the
others were measured and did not need one.

## Layout

Breakpoints are 380, 480, 640, 768, 860, 900 and 1180. Everything that must clear
the fixed nav derives from two tokens and never computes the offset by hand:
`--chrome-h` is nav-top + nav-h + notice-h, and `--nav-clear` is that plus 8px.
`tests/unit/notice-strip-reserves-height.test.js` fails on any hand-rolled copy,
because a rule that spells the offset out itself ends up under the notice strip
the moment one appears.

## Shapes

The radius ramp is in the frontmatter. Rounding is a user setting, stored under
`vs-appearance`, so no component may hard-code a radius — read the token, or the
setting does nothing.

## Do's and Don'ts

- **Do** change values in `src/styles/global.css` and regenerate this file.
- **Do** check both themes and reduced motion. All three ship.
- **Don't** hand-edit this file. The drift test fails and the edit is lost.
- **Don't** add a second copy of a design value to any document. Every doc table
  of design values in this repository has drifted from the stylesheet at least
  once, which is why this one is generated.
- **Don't** treat equal visual weight as neutral. Six equal cards for six unequal
  things is on the anti-slop tell list —
  `.claude/skills/uil4b-brand-design/references/anti-slop-quality-bar.md`.
